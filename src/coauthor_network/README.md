# coauthor_network

トヨタ関連企業4組織の論文について、共著ネットワークの固定化（以前に共著したことのある相手と、また組んでいるか）を数値にし、論文の新規性（shibayama_novelty の `Novel_q`）との関係を調べる。

仮説: 共著ネットワークが固定化している論文ほど、新規性が小さい（2026-10-02 の打ち合わせで、トヨタの方から「共著の組み合わせが固定化している」という話があった）。

## 指標

論文単位（チームの人数を m とする）:

- くり返しの組の割合 =（それ以前に共著したことのある2人の組の数）÷ m(m−1)/2。Guimerà ら（2005）の repeat incumbent–incumbent links の割合、Zeng ら（2021）の link freshness の裏返しにあたる
- 既知のメンバーの割合 =（チームのほかの誰かと、それ以前に共著したことのある人の数）÷ m。Zeng ら（2021）の node freshness の裏返しにあたる

「それ以前」は出版年が前の論文（同じ年は数えない）で、データにある論文（917本）の中でしか分からない。

ネットワーク全体: 組織ごと・期間ごとの共著ネットワークのスモールワールド指数 Q（Uzzi & Spiro 2005）。

## 工程

上から順に流す。各工程の入出力はスクリプト先頭の docstring に書いてある。

| # | スクリプト | 内容 | 出力（`data/derived/coauthor_network/`） |
|---:|---|---|---|
| 1 | `src/coauthor_network/identify_authors.py` | 全著者（社外の共著者を含む）を区別し、所属を toyota / external / unknown に分ける。区別の規則は独自 | `authors/` |
| 2 | `src/coauthor_network/compute_team_familiarity.py` | 論文ごとに、くり返しの組の割合・既知のメンバーの割合・以前の共著数の平均を、4つの版（全著者 / トヨタ側 × 記録が組織をまたぐ / 組織ごと）で計算する。回帰から除く論文に印を付ける（データの始まりの決め方と除く年数は独自） | `team/` |
| 3 | `src/coauthor_network/regress_novelty_on_familiarity.py` | `Novel_100`・`Novel_50` を、くり返しの組の割合・既知のメンバーの割合で OLS 回帰する（統制: log(著者数)・log(参考文献数)・出版年・組織・分野、HC3）。4つの版と、除く年数 1〜3 で確かめる。統制変数の選び方と回帰に使う論文の絞り方は独自 | `regression/` |

工程に入れないスクリプト:

- `src/coauthor_network/check_orcid_names.py` — `authorships.csv` の ORCID を、ORCID の公開記録の名前と照らし合わせ、名前が合わない行を `data/review/orcid_name_mismatches.csv` に書き出す。外部の API を引くので工程に入れない。応答は名前の項目だけを `data/cache/orcid/` に保存する（2026-11-05 取得）。書き出した行は人が確かめ、`is_wrong_orcid` と `note` に判断を書く。流し直しても判断は残る。

## 再現

```sh
for s in identify_authors compute_team_familiarity regress_novelty_on_familiarity; do
  .venv/bin/python src/coauthor_network/$s.py
done
```

`notebooks/reproduce/reproduce_coauthor_network.ipynb` は同じ工程を流し、`data/derived/coauthor_network/` の全ファイルがコミットされたものとバイト単位で一致するかを確かめる。

### 工程2 論文ごとの指標

「以前の共著」の記録には、出版年が分かる857本を、4組織をまたいで使う（同じ論文が2サイトに載っている5件は1回だけ。回帰から除く論文も記録には入る）。指標を計算できた論文（チームが2人以上）は、全著者版 818本、トヨタ側版 639本。

4つの版を作る（メンバー × 「以前の共著」の記録の範囲）。`_org` の版は、同じ組織の論文だけを記録に使う（その組織の中での固定化。組織を移った人の、前の組織での共著は数えない）。

| 指標（平均） | 全著者・組織をまたぐ（`all`） | トヨタ側・組織をまたぐ（`toyota`） | 全著者・組織ごと（`all_org`） | トヨタ側・組織ごと（`toyota_org`） |
|---|---:|---:|---:|---:|
| くり返しの組の割合 | 0.310 | 0.371 | 0.307 | 0.366 |
| 既知のメンバーの割合 | 0.442 | 0.476 | 0.437 | 0.469 |
| 以前の共著数の平均 | 1.17 | 1.78 | 1.17 | 1.77 |
| 以前の共著が1組も無い論文の割合 | 37.9% | 41.5% | 38.8% | 42.6% |

組織をまたぐ版と組織ごとの版の差は小さい（組織をまたいだ共著は少ない）。

組織の「データの始まり」（1年間の論文数が初めて3本以上になった年。累計ではない）: AISIN IMRA（米国）1993、AISIN IMRA（日本）2004、未来創成センター 2018、豊田中央研究所 2018。最も古い年にしないのは、出版年が明らかにおかしい論文があるため（AISIN IMRA 米国に year_openalex が 1946 と 1968 の論文、豊田中央研究所に公式サイトの年と11〜12年ずれる論文が2本）。

### 工程3 Novelty との回帰

主に見るのは全著者・記録は組織をまたぐ版、除く年数2（610本）。係数は割合が 0 から 1 に変わったときの Novel_q の変化。

| 目的変数 | 説明変数 | 係数 | 95% 区間 | p |
|---|---|---:|---|---:|
| Novel_100 | くり返しの組の割合 | −0.003 | [−0.029, +0.024] | .84 |
| Novel_100 | 既知のメンバーの割合 | −0.009 | [−0.034, +0.016] | .49 |
| Novel_50 | くり返しの組の割合 | +0.008 | [−0.011, +0.027] | .39 |
| Novel_50 | 既知のメンバーの割合 | +0.005 | [−0.013, +0.024] | .57 |

- どの版（トヨタ側、組織ごと）でも、除く年数を 1・3 にしても、有意な関係は無い（すべて p ≥ .10）。
- 95% 区間は狭い。割合が 0.5 違っても、Novel_100 の差は標準偏差（0.198）の8%以下、Novel_50 の差は標準偏差（0.118）の12%以下に収まる。仮説（固定化しているほど新規性が小さい）に当たる、意味のある大きさの関係は無い。
- 2つの指標は強く相関する（r = 0.917）。両方を入れたモデル（RK）で係数の向きが逆になるのはこのためで、RK の結果は解釈しない。
- 言えるのは「このデータの中で観察できる共著の履歴による固定化」との関係まで。公式サイトの論文に載っていない共著（社外の論文、データの期間より前の論文）は数えられていない。
